# homebrew-tap

Homebrew tap for [Damon](https://github.com/developjik/damon-agent-core).

```sh
brew install developjik/tap/damon
```

`Formula/damon.rb` is generated by `scripts/update-tap-formula.sh` in damon-agent-core — version and sha256 are computed from the published release tarballs, not edited by hand.
